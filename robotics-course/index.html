หน่วยการเรียนรู้

ข้อควรทราบ: บทเรียน ROS นี้ออกแบบตาม Ubuntu 22.04 + ROS 2 Humble; Mac Apple Silicon ให้ใช้ Ubuntu ARM64 ไม่ใช่ x86 ISO ใน VMware Fusion. หุ่นยนต์จริงต้องทดสอบระบบหยุดฉุกเฉิน แยกภาคจ่ายไฟมอเตอร์ และยกล้อพ้นพื้นก่อนทดลองทุกครั้ง

Virtual Robot Lab (VR/3D)

🥽🤖

ห้องเรียนเสมือน 3 มิติ

สำรวจโมเดลหุ่นยนต์และองค์ประกอบในฉาก 3D หมุนมุมมองด้วยเมาส์/สัมผัส และเข้าสู่โหมด VR ในอุปกรณ์ที่รองรับ WebXR

ภารกิจ VR

1. หาตำแหน่งตัวควบคุม เซนเซอร์ มอเตอร์ และแบตเตอรี่ในฉาก

2. อธิบายเส้นทางข้อมูล Sense → Plan → Act

3. เปรียบเทียบโมเดลกับหุ่นยนต์ Raspberry Pi 4 จริง

ฉาก 3D เป็นสื่อเรียนรู้ประกอบ ไม่ใช่ตัวจำลองฟิสิกส์หรือ ROS simulator ที่เชื่อมกับมอเตอร์

ระบบบันทึกผลประเมินนักเรียน

☁️ สมุดประเมินกลางสำหรับครู

บันทึกผลจริงลงฐานข้อมูลส่วนกลาง โดยใช้รหัสครู มีแบบประเมินพฤติกรรม 5 ข้อและคุณลักษณะ 6 ข้อ แสดงคะแนนรายข้อ แก้ไขรายบุคคล และส่งออก CSV

รุ่นเริ่มต้นบันทึกใน localStorage ของเบราว์เซอร์เท่านั้น ผู้เรียนหรือครูที่ใช้อุปกรณ์อื่นจะยังไม่เห็นข้อมูลชุดเดียวกัน **อย่าถือเป็นฐานข้อมูลกลาง** และโปรดใช้รหัสนักเรียนที่ไม่ใช่เลขบัตรประชาชน พร้อมส่งออก CSV สำรอง

พฤติกรรมการทำงานรายบุคคล (5 ข้อ คะแนนเต็ม 15)

คุณลักษณะอันพึงประสงค์ (6 ข้อ คะแนนเต็ม 18)

การนำเข้าใช้ไฟล์ JSON สำรองจากปุ่มด้านบน (CSV ส่งออกสำหรับ Excel)
