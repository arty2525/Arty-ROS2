# สัปดาห์ที่ 8 — Motor Driver, PWM และ Direction

**เวลา:** 100 นาทีต่อเนื่อง

## จุดประสงค์
อธิบาย PWM/DIR และ Motor Driver, ตรวจ wiring และทดสอบทิศมอเตอร์แบบยกล้อได้

## กิจกรรมการเรียนรู้ 100 นาทีต่อเนื่อง
### 1. Engage — 10 นาที
ถามเหตุใด ESP32 จึงไม่ควรจ่ายกำลังให้มอเตอร์โดยตรง.

### 2. Explore — 25 นาที
สำรวจ `ESP32 PWM/DIR → Cytron MDD10A → Motor` และ `Encoder A/B → ESP32`; วาดแยก logic/control กับ motor power และระบุจุดตรวจแรงดัน/ขั้ว.

### 3. Explain — 20 นาที
อธิบาย PWM duty cycle, direction, driver/current path และเหตุผลที่ software command ไม่ใช่แหล่งกำลังมอเตอร์.

### 4. Safety Gate + Elaborate — 30 นาที
ก่อนจ่ายกำลังต้องผ่าน:
- [ ] หุ่นบนแท่น ล้อขับพ้นพื้น
- [ ] ไม่มีสายแตะล้อ/เพลา
- [ ] ตรวจขั้ว/สาย driver
- [ ] ผู้ควบคุมคำสั่ง 1 คน
- [ ] ตัดไฟได้ทันที
- [ ] เริ่ม command ต่ำตามข้อกำหนดครู

เมื่อผ่านจึงทดสอบมอเตอร์ทีละข้างและบันทึก “คำสั่งเชิงบวก → ทิศทางทางกายภาพ”. ห้ามแก้ inversion ก่อนมีหลักฐานจริง.

### 5. Evaluate — 15 นาที
ส่ง motor direction table + wiring diagram + signed safety checklist.

## หลักวิศวกรรม
หากทิศผิด ห้ามสลับสายหลายจุดพร้อมกัน; เปลี่ยนตัวแปรครั้งละหนึ่งอย่างและบันทึกก่อน/หลัง.
