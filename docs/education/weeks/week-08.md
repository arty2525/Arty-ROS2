# สัปดาห์ที่ 8 — Motor Driver, PWM และ Direction

**เวลา:** 100 นาที

## จุดประสงค์
นักเรียนอธิบาย PWM/DIR และบทบาท Motor Driver, ตรวจ wiring ด้วย checklist และทดสอบทิศมอเตอร์แบบยกล้อได้.

## คาบที่ 1
### Engage — 10 นาที
คำถาม: เหตุใด ESP32 จึงไม่ควรจ่ายกำลังให้มอเตอร์โดยตรง?

### Explore — 25 นาที
นักเรียนสำรวจ signal path:
`ESP32 PWM/DIR → Cytron MDD10A → Motor`
และ feedback path:
`Encoder A/B → ESP32`.

ให้นักเรียนวาดแยก **logic/control** กับ **motor power** และระบุจุดที่ต้องตรวจแรงดัน/ขั้ว.

### Explain — 15 นาที
อธิบาย PWM duty cycle, direction, driver, current path และเหตุผลที่ software command ไม่ใช่แหล่งกำลังของมอเตอร์.

## คาบที่ 2
### Safety Gate — 15 นาที
ก่อนจ่ายกำลังทุกกลุ่มต้องผ่าน:
- [ ] หุ่นอยู่บนแท่น ล้อขับพ้นพื้น
- [ ] ไม่มีสายแตะล้อ/เพลา
- [ ] ตรวจขั้วและสาย driver
- [ ] มีผู้ควบคุมคำสั่ง 1 คน
- [ ] มีวิธีตัดไฟทันที
- [ ] เริ่มจาก command ต่ำตามข้อกำหนดของครู

### Elaborate — 20 นาที
ทดสอบมอเตอร์ทีละข้างและบันทึก “คำสั่งเชิงบวก → ทิศทางทางกายภาพ”. **อย่าแก้ inversion จนกว่าจะมีหลักฐานจากการทดลองจริง**.

### Evaluate — 15 นาที
ส่ง motor direction table, wiring diagram และ safety checklist ลงชื่อผู้ตรวจ.
