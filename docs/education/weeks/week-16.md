# สัปดาห์ที่ 16 — การวัดพารามิเตอร์ทางกายภาพของหุ่นยนต์

**รายวิชา:** ระบบปฏิบัติการหุ่นยนต์ • **ระดับชั้น:** ม.4 • **เวลา:** 100 นาทีต่อเนื่อง

## จุดประสงค์
นักเรียนสามารถวัดและบันทึกพารามิเตอร์จริงของหุ่นยนต์อย่างเป็นระบบ แยกค่าที่ยืนยันแล้วออกจากค่าที่ยังไม่ทราบ และอธิบายผลของค่าทางกายภาพต่อ URDF, Differential Drive และ Odometry ได้

## ค่าที่ทราบแล้ว
- ล้อขับ 2 ล้อ อยู่กึ่งกลางด้านซ้ายและขวาของฐาน
- เส้นผ่านศูนย์กลางล้อขับ 65 mm
- `wheel_radius = 0.0325 m`
- Caster Ball 2 ลูก อยู่ด้านหน้าและด้านหลัง เป็นล้อประคอง

## ค่าที่ต้องวัดจากหุ่นจริง
- wheel separation: ระยะระหว่างแนวกึ่งกลางล้อขับซ้าย–ขวา
- wheel width
- base length / width / height
- caster ball radius
- front/rear caster offsets ตาม reference frame ที่กำหนด

## อุปกรณ์
ไม้บรรทัดเหล็ก/ตลับเมตร, เวอร์เนียร์คาลิปเปอร์ถ้ามี, เทปทำเครื่องหมาย, Engineering Logbook, หุ่นยนต์ที่ปิด Motor Power

## กิจกรรมการเรียนรู้ 100 นาทีต่อเนื่อง
### 1. Engage — 10 นาที
ครูแสดงค่า `wheel_separation` ในสมการ Differential Drive แล้วถามว่า “ถ้าค่านี้ผิด 2–3 cm จะเกิดอะไรกับการหมุนและ odometry?” นักเรียนคาดการณ์ก่อนวัดจริง

### 2. Explore — 25 นาที
แต่ละกลุ่มกำหนด reference points และวัดค่าทางกายภาพ โดยสมาชิกอย่างน้อย 2 คนอ่านค่าซ้ำอย่างอิสระ บันทึกหน่วยและเครื่องมือทุกครั้ง

### 3. Explain — 20 นาที
อธิบายความต่างระหว่าง precision, accuracy, repeatability และ measurement uncertainty. เน้นการใช้ SI unit ใน ROS 2: เมตร, วินาที, เรเดียน

ครูอธิบายว่าค่าทางกายภาพเดียวกันอาจถูกใช้หลายชั้น เช่น wheel separation มีผลต่อ robot model และ diff-drive kinematics จึงต้องมีแหล่งข้อมูลจริงเพียงแหล่งที่ตรวจสอบย้อนกลับได้

### 4. Elaborate — 30 นาที
นักเรียนคำนวณค่าเฉลี่ย เปรียบเทียบความต่างของแต่ละ trial และทำ Physical Parameter Record พร้อมภาพตำแหน่งที่วัด จากนั้นตรวจ config ปัจจุบันโดยไม่แก้ค่าจนกว่าครูอนุมัติ:
```bash
cd ~/Arty-ROS2
python3 scripts/validate_robot_config.py
```
อภิปรายว่าค่า `0.0` ที่ใช้เป็น fail-safe หมายถึง “ยังไม่ resolve” ไม่ใช่ค่ากายภาพจริง

### 5. Evaluate — 15 นาที
ส่ง Physical Parameter Record + ภาพ/diagram จุดวัด + ตารางค่าที่ยืนยันแล้ว/ยังไม่ยืนยัน + Exit Ticket

## Safety
ปิด Motor Power ระหว่างวัด • ห้ามสอดมือใกล้ล้อที่สามารถหมุนได้ • วางหุ่นบนพื้น/แท่นมั่นคง • ไม่ใช้ค่าจากอินเทอร์เน็ตแทนการวัดหุ่นจริง

## เกณฑ์
วัดซ้ำ ≥3 ครั้ง • หน่วยถูกต้อง 100% • ระบุ reference point ชัดเจน • ไม่สร้างค่าที่ไม่ได้วัด • teamwork ≥3/4
