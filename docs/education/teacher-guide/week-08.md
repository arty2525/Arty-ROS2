# คู่มือครู Week 08 — Motor Driver, PWM และ Direction

**เวลา:** 100 นาทีต่อเนื่อง  
**ใช้คู่กับ:** `docs/education/weeks/week-08.md`

## ความรู้ที่ครูควรทบทวน
Motor Driver ทำหน้าที่เป็นวงจรกำลังระหว่าง ESP32 กับมอเตอร์ ESP32 ส่งเพียงสัญญาณควบคุม เช่น PWM/DIR ส่วน Driver จ่ายกระแส/แรงดันให้มอเตอร์ตามวงจรกำลัง

### PWM คืออะไร
PWM ย่อจาก Pulse Width Modulation เป็นการสลับสัญญาณ ON/OFF ด้วยความถี่คงที่และปรับสัดส่วนเวลาที่เป็น ON หรือ duty cycle เพื่อควบคุมค่ากำลังเฉลี่ยที่มอเตอร์ได้รับในเชิงควบคุม

อย่าสอนว่า “PWM 50% = มอเตอร์หมุนครึ่งความเร็วเสมอ” เพราะความเร็วมอเตอร์จริงขึ้นกับโหลด แรงดัน แรงเสียดทาน และระบบควบคุม

### DIR คืออะไร
Direction signal ใช้กำหนดทิศทางการขับของ Motor Driver ตาม mode/วงจรที่ใช้งาน การตีความ HIGH/LOW ว่าหมุนไปทางไหนต้องยืนยันจากการต่อจริงและ convention ของระบบ

## การเตรียมก่อนสอน
1. ตรวจ datasheet/คู่มือ MDD10A ที่ใช้จริง
2. ตรวจสาย Motor Power และ Logic Signal แยกกันชัดเจน
3. ตรวจ common ground ตามวงจรของระบบ
4. ยกหุ่นให้ล้อขับพ้นพื้น
5. เตรียมวิธีตัด Motor Power ทันที
6. ตรวจว่าไม่มีสายใกล้ล้อ/เพลา
7. ตรวจ GPIO PWM/DIR ตาม baseline ของ repository

## ขั้นตอนสอน 100 นาที
### นาที 0–10: Engage
ถามว่า “ทำไม ESP32 จึงไม่ต่อเข้ามอเตอร์โดยตรง?” คาดหวังคำตอบเรื่องกำลังไฟ/กระแสและหน้าที่ของ driver

### นาที 10–35: Explore
ให้นักเรียนตามสายจาก ESP32 ไป MDD10A แล้วจาก MDD10A ไป Motor แยกเป็น 2 กลุ่มเส้น:
- control signal
- motor power

ให้เด็กวาด wiring diagram แบบไม่ต้องใส่ค่าที่ไม่ทราบ

### นาที 35–55: Explain
อธิบาย PWM, duty cycle, DIR, Motor Driver และเหตุผลที่ “คำสั่ง software” กับ “พลังงานที่ขับมอเตอร์” เป็นคนละเรื่อง

ย้ำว่า motor direction ต้องอิง coordinate convention ของหุ่น ไม่ใช่แค่ “มอเตอร์หมุนตามเข็ม/ทวนเข็ม” เพราะล้อซ้ายและขวาติดตั้งกลับด้านกันทางกายภาพได้

### นาที 55–85: Elaborate + Safety Gate
ก่อนจ่าย Motor Power ทุกกลุ่มต้องผ่าน Checklist:
- ล้อพ้นพื้น
- ตรวจสายและขั้ว
- ไม่มีสิ่งกีดขวาง
- ผู้สั่งงาน 1 คน
- ผู้เฝ้าตัดไฟ 1 คน
- เริ่ม command ต่ำตามข้อกำหนดครู

### นาที 85–100: Evaluate
ตรวจตารางทิศ, wiring diagram และถามว่าทำไมไม่ควรสลับสายพร้อมแก้ inversion ใน software ในเวลาเดียวกัน

## จุดสับสน
**PWM = แรงดันคงที่ลดลง?** ไม่ตรงนัก PWM เป็นสัญญาณสลับที่ duty cycle เปลี่ยน ค่าเฉลี่ยเชิงผลต่อโหลดจึงเปลี่ยน

**มอเตอร์สองข้างใช้ DIR ค่าเดียวกันแล้วต้องเดินหน้าเหมือนกันเสมอ?** ไม่จำเป็น เพราะการติดตั้งล้อซ้าย/ขวาอาจทำให้ทิศเชิงกายภาพกลับกัน จึงต้องยืนยันด้วยการทดลอง

**มอเตอร์หมุน = ระบบถูกต้อง?** ยังไม่พอ ต้องตรวจทิศ, encoder sign, safety และ feedback

## Common problems
- มอเตอร์ไม่หมุน → ตรวจ Motor Power, driver enable/mode, signal, wiring, firmware state
- หมุนข้างเดียว → ตรวจ signal/wiring ของแต่ละ channel แยกกัน
- หยุดไม่ได้ → ตัด Motor Power และตรวจ timeout/command logic ก่อนทดลองต่อ
- ทิศผิด → บันทึกก่อนแก้ เปลี่ยนเพียงจุดเดียวและ re-test

## Safety
ห้ามจับล้อ/เพลาระหว่างจ่ายกำลัง ห้ามทดสอบโดยวางหุ่นบนพื้นครั้งแรก และห้ามเพิ่ม command เพื่อ “ดูว่าจะติดไหม” หากยังไม่ทราบสาเหตุ

## เนื้อหาขยาย
อธิบาย back-EMF, H-bridge และเหตุผลที่วงจรขับมอเตอร์ต้องรองรับพลังงานย้อนจากมอเตอร์ในระดับแนวคิด
