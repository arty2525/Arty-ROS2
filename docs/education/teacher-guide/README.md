# คู่มือครู — รายวิชาระบบปฏิบัติการหุ่นยนต์ ม.4

กลุ่มสาระการเรียนรู้ **วิทยาศาสตร์และเทคโนโลยี**  
ระยะเวลา **20 สัปดาห์ × 100 นาทีต่อเนื่อง = 2,000 นาที**  
แพลตฟอร์ม **Raspberry Pi 4 + Ubuntu 24.04 LTS + ROS 2 Jazzy + ESP32 + Cytron MDD10A + Encoder Motor**

คู่มือนี้จัดทำขึ้นสำหรับครูผู้สอน เพื่อใช้ **ทบทวนความรู้ก่อนสอน ขยายความเนื้อหา อธิบายเหตุผลเบื้องหลังแต่ละขั้นตอน เตรียมการทดลอง และป้องกันความสับสนของนักเรียน** โดยใช้ร่วมกับบทเรียนสำหรับนักเรียนใน `docs/education/weeks/`.

## วิธีใช้คู่มือครู
ก่อนสอนแต่ละสัปดาห์ ครูควรดำเนินการ 5 ขั้น:

1. **Review** — อ่านหัวข้อ “ความรู้ที่ครูควรทบทวน” ให้เข้าใจแนวคิดและคำศัพท์ก่อน
2. **Prepare** — เตรียมอุปกรณ์ ซอฟต์แวร์ สายไฟ และผลลัพธ์ตัวอย่างที่ถูกต้อง
3. **Pre-test system** — ทดลองคำสั่ง/อุปกรณ์ด้วยตนเองก่อนเข้าห้องเรียนอย่างน้อย 1 รอบ
4. **Teach by evidence** — ให้นักเรียนอธิบายจากสิ่งที่สังเกต/วัด ไม่ให้จำคำสั่งโดยไม่เข้าใจ
5. **Stop on uncertainty** — หากค่าฮาร์ดแวร์ไม่ทราบ ให้หยุดและวัด ห้ามใส่ค่าคาดเดาเพื่อให้ระบบทำงาน

## โครงสร้างมาตรฐานในแต่ละบทของคู่มือครู

- คำศัพท์และความหมาย
- การเตรียมระบบก่อนเข้าห้อง
- ลำดับการสอน 100 นาทีอย่างละเอียด
- จุดที่นักเรียนมักสับสน
- คำถามชี้นำและคำตอบที่ครูควรคาดหวัง
- วิธีสาธิตและผลที่ควรเห็น
- วิธีแก้ปัญหาเมื่อผลไม่ตรงที่คาด

## หลักการสำคัญที่ครูต้องย้ำตลอดรายวิชา

### 1. Hardware truth มาก่อน software convenience
ค่าที่มีผลต่อการเคลื่อนที่ เช่น wheel separation, encoder TPR, inversion หรือ PID ต้องมาจากการวัด/ทดลองจริง ไม่ใช่ตัวเลขจากอินเทอร์เน็ตหรือหุ่นรุ่นใกล้เคียง

### 2. แยก “อาการ” ออกจาก “สาเหตุ”
ตัวอย่าง: “หุ่นไม่วิ่ง” เป็นอาการ ไม่ใช่สาเหตุ สาเหตุอาจเป็น controller inactive, UART หลุด, firmware fault, invalid configuration, Motor Power ไม่มา หรือ wiring ผิด

### 3. เปลี่ยนทีละหนึ่งตัวแปร
เวลาทดลองหรือแก้ปัญหา ห้ามเปลี่ยนสาย + parameter + code พร้อมกัน เพราะจะไม่ทราบว่าอะไรทำให้ผลเปลี่ยน

### 4. นักเรียนต้องบันทึกหลักฐาน
ทุกกิจกรรมควรมีอย่างน้อยหนึ่งอย่าง: Terminal log, screenshot, measurement table, configuration diff, Git commit SHA, diagnostic output หรือ Engineering Logbook

### 5. ความปลอดภัยมาก่อนความสำเร็จของภารกิจ
การทดลองมอเตอร์ครั้งแรกต้องยกล้อพ้นพื้น, จำกัดความเร็ว, มีผู้ควบคุมหนึ่งคน, มีวิธีตัดไฟ และหยุดทันทีเมื่อพฤติกรรมผิดปกติ
