# การตรวจสอบพารามิเตอร์กายภาพโดยไม่ใช้ค่าจำลอง

Arty-ROS2 ใช้ `ros2_ws/src/mobile_robot_bringup/config/robot.yaml` เป็นแหล่งข้อมูลจริงสำหรับค่ากายภาพและค่าคาลิเบรตของฐานหุ่นยนต์

ค่าที่ได้รับการยืนยันแล้วในปัจจุบันคือรัศมีล้อขับ `0.0325 m` จากล้อเส้นผ่านศูนย์กลาง `65 mm` เท่านั้น ค่าที่ต้องวัดจริงและยังไม่ได้ยืนยันให้คงเป็น `0.0` ห้ามใส่ค่าประมาณเพื่อทำให้ verification ผ่าน

สคริปต์ `scripts/validate_robot_config.py` ตรวจสอบชนิดข้อมูล ค่า finite ค่าที่ห้ามติดลบ ค่า boolean และรัศมีล้อที่ยืนยันแล้ว โดยโหมดปกติอนุญาต `0.0` สำหรับค่าที่ยังไม่ได้วัด ส่วนการตรวจความพร้อมก่อนใช้งานจริงให้ใช้:

```bash
python3 scripts/validate_robot_config.py \
  ros2_ws/src/mobile_robot_bringup/config/robot.yaml \
  --require-complete
```

คำสั่งนี้ต้องไม่ผ่านจนกว่าค่ากายภาพ ค่าตัวเข้ารหัส และ limits ที่จำเป็นจะถูกวัดหรือยืนยันครบ

`verify_phase1b_part16.sh` จะอ่านค่าจาก `robot.yaml` โดยตรงเพื่อสร้าง URDF สำหรับตรวจโครงสร้าง จึงไม่มีการฝังค่า TPR ระยะล้อ ขนาดฐาน หรือขนาด/ตำแหน่ง caster แบบสมมติใน verifier อีกต่อไป
