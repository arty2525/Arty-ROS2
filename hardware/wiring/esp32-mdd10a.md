# การต่อ ESP32 กับ Cytron MDD10A Rev2.0

| MDD10A | ESP32 |
|---|---:|
| PWM1 | GPIO25 |
| DIR1 | GPIO26 |
| PWM2 | GPIO27 |
| DIR2 | GPIO14 |
| GND | GND |

มอเตอร์ซ้ายต่อกับ `M1A/M1B` และมอเตอร์ขวาต่อกับ `M2A/M2B`

- แหล่งจ่ายมอเตอร์เป็นวงจรแยกจาก 5V/3.3V logic
- ESP32, MDD10A และ Raspberry Pi ต้องมีกราวด์อ้างอิงร่วมกัน
- ต้องติดตั้งฟิวส์ที่สายแบตเตอรี่ก่อนเข้ามอเตอร์ไดรเวอร์
- ต้องมี Emergency Stop ทางฮาร์ดแวร์
